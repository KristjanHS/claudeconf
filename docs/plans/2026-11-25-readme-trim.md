# README trim: critique and recommendations

Target: `README.md` (503 lines, ~4,100 words, 31 emoji, 99 bold spans, ~86 spaced-hyphen dashes).
Goal: cut it to about a quarter of its length (~120–150 lines), remove the AI-sounding prose, and drop the emoji.

## Diagnosis

The README is a hub that also tries to be the catalog, the design doc, the evidence log and the
adoption guide. Most of its length repeats `docs/system.md`, `docs/why.md`, `ADOPT.md` and
`.claude/hooks/README.md`.

Detection pass (`detect-ai-text-cl-op`): the sentence statistics look human-ish (burstiness 0.96).
That is mostly because tables and lists break up the prose. The structural tells are strong:
template parallelism, layered signposting, repeated caveats and heavy bolding. Verdict: **mixed /
AI-drafted and human-edited**. Pattern-matching only, not proof.

## 2. Emoji

- 31 emoji: one on every `##` heading plus a duplicate in the TOC. They add colour, not meaning.
  Remove them all. If you want visual structure, the badges and the statusline GIF are enough.
- **Coupling, so do this in one commit:** GitHub slugs the emoji into the anchor (`## 🤝 Adoption` →
  `#-adoption`). Removing the emoji changes every anchor to `#adoption` and so on, which breaks:
  - `docs/system.md` (lines 3, 21, 25, 26, 48, 49, 85, 88) and `docs/why.md` (lines 5, 14, 30, 31, 42, 48)
  - `tests/test_readme_hub.py`: the hardcoded `#-adoption` set (line 75), the parametrized
    `-does-this-actually-work` / `-adoption` fragments (lines 104–105) and the planted fixture (line 128)
  - Run `make -C ~/projects/claudeconf test` after the rename. `test_hub_targets_resolve` and
    `test_docs_readme_anchors_resolve` will flag any anchor that was missed.
- Deleted sections (Glossary, How it works, Beyond context, skills detail) also drop anchors that
  `docs/` cites. Re-point those cites to `docs/catalog.md` / `docs/system.md`.

## 3. AI-slop patterns to remove

| Pattern | Examples (line) | Fix |
|---|---|---|
| Sincerity markers | "The honest question" (133), "Scoped honestly" (144), "genuinely information-rich" (233) | Delete the marker and state the claim |
| Pre-emptive skeptic framing | "A skeptic should weigh the tax, not just the upside" (214), "written for someone already running Claude Code who doubts…" (132) | Delete. A heading like "Costs and limits" says it |
| Page-about-the-page signposting | "Where each layer of the method lives on this page" (71), "is what the rest of this page tries to answer" (134), "Every piece and what it's for. Terse by design;" (291), "Grouped by what each piece does: …" (295) | Delete every sentence whose subject is the README itself |
| "Not X, but Y" / aphorism closers | "Each layer is a file you can read and copy, not a description of one." (55–56), "instead of auto-compaction eventually kicking in and silently dropping detail that mattered" (394) | Cut, or state the fact plainly |
| Triplets and rule-of-four | Tagline: "rules, gates, a review loop and a cost budget - each layer … you can read, run and copy"; "slow, expensive, and forgetful" (117) | Keep one list per sentence. The tagline should be ≤12 words, e.g. *"My Claude Code config: rules, hooks and a context budget, ready to copy."* |
| Repeated hedges/caveats | "secondary" ×3 (139, 246, 400), "fails open" ×2, "bypassable" ×2, "(a rough heuristic, not a tokenizer count)" | Say each caveat once, where it matters |
| Indirection to table rows | "(count: the *Hooks* row of the measured table)" (216), "(band values: the `BANDS` table and `HARD_STOP_TOKENS` …, both rows of the measured table)" (365–367) | Either write the number inline or drop the parenthetical. Pointing at a row on the same page is reader-hostile |
| Bold everywhere | 99 bold spans; bold opening phrase on nearly every bullet and paragraph | Bold only list-item labels in the catalog; no mid-paragraph bold |
| Spaced hyphen as em-dash | ~86 `" - "` joins | Use periods, commas or colons. Most of these clauses read better as two sentences |
| Template parallelism | 6 identical `Piece / Purpose / How it works / Cost` tables; "None until triggered" ×8; every skill bullet is "**`name`** - verb …" | Collapsing to one summary table fixes this as a side effect |
| Label-colon intros | "**The message it sends.**", "**What actually happened**", "**Context-hygiene core** - the leanness toolkit:" | Plain sentences, or nothing |
